# Changelog

## 0.1.0 — 2026-09-07

First public release of Sidequest: a native Omarchy quest journal for installed Steam games.

- Local multi-library index, cached cover art, and original fallback landscapes.
- Next-session notes, favourites, explicit session tags, and reversible hiding.
- A filtered shuffle bag that works through games before repeating.
- Keyboard-driven Steam launch handoff with numeric app IDs.
- Independent fictional demo, private atomic state, and no idle daemon.
- Compact layouts, reduced motion, shared multi-monitor backend, and tested helper recovery.
